# Fort brand kit

Not consumed by the Control Panel or email templates yet. Later work can adopt these for dashboard CSS, HTML emails ([#36](https://github.com/allomambo/craft-fort/issues/36)), and Plugin Store assets.

Source: [MM-DS-2023 → Couleurs](https://www.figma.com/design/n53H7LfhK5ImAs3V2egcQE/MM-DS-2023?node-id=1407-1605). Brand accent is pink 500 (`#FF9DDE`).

| File | What |
| --- | --- |
| `colors.css` | Palette as `--fort-color-*` (and `--fort-brand-pink-500`). Not imported. |
| `fonts.css` | Inter 400 / 600 / 700 `@font-face` rules. Not enqueued. |
| `../icon.svg` | Full-color Fort mark (plugin icon). |
| `../icon-mask.svg` | Monochrome mark used by the Craft CP nav. |
| `../resources/fort-icon.png` | Raster of the pink mark, for email later. |
